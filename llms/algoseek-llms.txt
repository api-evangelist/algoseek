# AlgoSeek

> AlgoSeek, LLC is a New York-based financial market data vendor selling historical intraday US market data — equities, ETFs, equity options with Greeks and IV, futures, futures options, and reference data — plus real-time feeds. Delivery is data-platform-first: S3 flat files, the ArdaDB managed ClickHouse cloud database (queried via the open-source algoseek-connector Python library), colocated MultiCast/TCP real-time feeds, and a REST Metadata Services API with a public OpenAPI 3.0.2 document.

## APIs

- [Metadata Services API (Swagger UI)](https://metadata-services.algoseek.com/docs): FastAPI metadata-api v1.2 — 148 paths (56 public catalog reads, 90 internal) covering datasets, data groups, pricing records, database tables, cloud storage buckets, documentation, vendors, and sample data. HTTP Bearer auth via POST /api/v1/login/access_token/.
- [Live OpenAPI 3.0.2 document](https://metadata-services.algoseek.com/api/v1/openapi.json): machine-readable contract for the Metadata Services API.
- [ArdaDB Query Service](https://algoseek.com/ardadb): managed ClickHouse cloud database (AWS us-east-1) pre-loaded with two petabytes of historical market data, queried with full SQL via the algoseek-connector Python library; no public HTTP base URL.
